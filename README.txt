KANFAR BUILDING — ВЕРСИЯ ДЛЯ ДЕМОНСТРАЦИИ

1. Распакуйте ZIP целиком.
2. Откройте папку Kanfar-Building-Demo.
3. Дважды нажмите index.html. Если файл открылся в редакторе, откройте его через Safari, Chrome или другой браузер.
4. Прокрутите страницу: в галерее проекты меняют угол и глубину.
5. Покажите карточки проектов, форму подбора и мобильную версию.

Изображения, шрифт, стили и анимации входят в архив. Для просмотра страницы интернет не нужен. Для переходов в WhatsApp, Instagram и 2ГИС интернет потребуется.

При демонстрации формы можно заполнить тестовые пожелания. Кнопка подготовки запроса открывает WhatsApp; сообщение отправляется только вручную в приложении.

Client-Presentation.txt — готовый текст для показа клиенту.
assets/manrope-license.txt — лицензия шрифта.
sources.json — происхождение изображений и информации о проектах.

Онлайн-версия сейчас доступна только автору. Этот архив можно показывать со своего ноутбука или переслать клиенту для локального просмотра.
